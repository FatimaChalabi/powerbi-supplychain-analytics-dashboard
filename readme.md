# 📦 Supply Chain Analytics Dashboard

End-to-end Power BI dashboard for supply chain performance monitoring — supplier scorecards, inventory health, procurement cost tracking, and a what-if lead-time simulator.

## 🎯 Project Goals
- Track supplier on-time delivery, defect rate, and lead time
- Monitor inventory turnover and stockout risk (ABC classification)
- Compare procurement budget vs actual cost
- Simulate the impact of lead-time and supplier changes on inventory levels
